# NOKTO DEVPROOF – nedlasting

Her ligger installasjonsfilene for **NOKTO DEVPROOF** for Windows. Repoet inneholder bare ferdige, signerte bygg – ingen kildekode.

## Last ned

**[Last ned nyeste versjon](https://github.com/noktohq/nokto-devproof-download/releases/latest)**

Velg filen `NOKTO.DEVPROOF_<versjon>_x64-setup.exe` under «Assets» og kjør den. Programmet installeres for din Windows-bruker.

## Windows SmartScreen

Viser Windows «Windows beskyttet PC-en», klikker du **Mer info** og deretter **Kjør likevel**.

## Oppdateringer

Appen ser selv etter nye versjoner her og installerer dem. Hver oppdatering er signert, og appen kontrollerer signaturen før noe installeres. Du kan også se etter oppdatering under **Innstillinger → Om → Se etter oppdatering**.
