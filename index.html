Problemet

«Hva har du egentlig gjort?»

Du har levert commits, pull requests og utgivelser. Timelisten sier «utvikling 7,5 t». DEVPROOF kobler tiden til leveransene, så kunden ser arbeidet – og du slipper å forsvare fakturaen.

01

Tid med kilde

Arbeidsdagen registreres fra PC, VS Code, Claude Code og Git. Hver time peker på noe du kan vise til.

02

Leveranser fra GitHub

Commits, pull requests og utgivelser hentes automatisk og kobles til riktig prosjekt og kunde.

03

Rapport med din logo

Én knapp gir kunden en ryddig PDF med din logo og farge, klikkbare referanser og tydelig skille mellom dokumentert og estimert.

Slik virker det

Spørsmål

Ofte spurt.

Finner du ikke svaret? Skriv til edin@nokto.no.

Hva skjer etter at jeg har betalt?

Du kommer rett til nedlastingen, og du får en e-post fra oss innen én arbeidsdag.

Fungerer det på Mac eller Linux?

Foreløpig bare Windows.

Ser kunden dataene mine?

Nei. Alt lagres lokalt på din PC. Kunden ser bare rapporten du selv velger å eksportere og sende.

Trenger jeg GitHub?

GitHub gir leveranser og prosjekter automatisk. Tid fra PC, VS Code og Claude Code registreres også uten.

Windows sier «Windows beskyttet PC-en». Er det farlig?

Nei. Installasjonsfilen er ennå ikke kodesignert, så Windows kjenner den ikke igjen. Velg «Mer info» og «Kjør likevel».

Kan jeg si opp?

Ja. Abonnementet betales forskuddsvis for ett år og fornyes automatisk. Send en e-post til edin@nokto.no før fornyelsesdatoen, så stopper vi fornyelsen. Du beholder tilgangen ut perioden du har betalt for. Allerede betalte perioder refunderes ikke.
