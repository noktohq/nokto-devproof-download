Kilder

Fra git log til faktura.

Fem kilder flettes inn i én tidslinje. Prosjektene gjenkjennes automatisk.

windows-aktivitet
Aktiv eller inaktiv, og hvilket program som er i forgrunnen (bare filnavnet, f.eks. Code.exe). Aldri vindustitler eller hva du skriver.
vscode
Økter i editoren, via utvidelsen.
claude-code
Økter, via hooks.
git
Repo og gren for mappen du jobber i. Commits leses ikke lokalt.
github
Commits, pull requests, utgivelser og CI.
Problemet

Timelisten lyver ikke. Den sier bare ingenting.

Du har levert commits, pull requests og utgivelser. Timelisten sier «utvikling 7,5 t». DEVPROOF kobler tiden til leveransene, så kunden ser arbeidet – og du slipper å forsvare fakturaen.

Slik virker det

Fire steg. Ingen timeliste.

Prøv Byrå gratis i 14 dager

Alle priser er eks. mva; 25 % mva kommer i tillegg. 14 dager gratis på begge planene: kortet legges inn i Stripe-kassen, og ingenting trekkes før prøveperioden er over. Si opp før dag 14, så betaler du ingenting. Deretter fornyes abonnementet hvert år; si opp før fornyelsesdatoen. Betalte perioder refunderes ikke. Byrå krever firmanavn i kassen. Sikker betaling via Stripe. Koden BLACKFRIDAY50 legges inn automatisk på Solo når du kjøper fra denne siden. Byrå har ikke Black Friday-rabatt.

Spørsmål

--help Spørsmål og svar

Finner du ikke svaret? Skriv til edin@nokto.no.

Er det gratis prøveperiode?

Ja, 14 dager. Du legger inn kort i Stripe-kassen, men ingenting trekkes før prøveperioden er over. Sier du opp før dag 14, betaler du ingenting.

Hva er forskjellen på Solo og Byrå?

Solo er for én utvikler. Byrå er for opptil fem utviklere på én faktura. Appen og funksjonene er de samme.

Hva skjer etter at jeg har betalt?

Du kommer rett til en side med lisensnøkkelen og nedlastingen. Ta vare på nøkkelen, for eksempel i passordbehandleren din.

Fungerer det på Mac eller Linux?

Foreløpig bare Windows.

Ser kunden dataene mine?

Nei. Alt lagres lokalt på din PC. Kunden ser bare rapporten du selv velger å eksportere og sende.

Trenger jeg GitHub?

GitHub gir leveranser og prosjekter automatisk. Tid fra PC, VS Code og Claude Code registreres også uten.

Kan jeg si opp?

Ja. Abonnementet betales forskuddsvis for ett år og fornyes automatisk. Send en e-post til edin@nokto.no før fornyelsesdatoen, så stopper vi fornyelsen. Du beholder tilgangen ut perioden du har betalt for. Allerede betalte perioder refunderes ikke.
